# #16 Add a regex search box to the tag list

이슈: https://github.com/alchemine/comfyui-daam-pack/issues/16

## 이슈

태그가 많으면 Tag Explorer 목록에서 원하는 태그를 찾기 어렵다.

## 해결책

`view` 버튼 아래에 검색창을 둔다.

- 입력한 정규식에 맞는 태그만 목록에 보인다. 대소문자는 구분하지 않는다.
- 빈 칸이면 모든 태그를 보인다.
- 정규식이 틀리면 모든 태그를 보이고 검색창 테두리를 빨갛게 한다.
- 검색어는 다음 생성 때도 남고, 브라우저를 새로 고치면 사라진다.
- 화살표 키는 보이는 태그 사이에서만 움직인다. 목록 전체 순서는 `sorted`,
  그중 보이는 부분은 `order`에 둔다.
- 검색창의 `keydown`은 노드로 올려 보내지 않는다. 스페이스와 Enter가 태그
  고정으로, 나머지 키가 그래프 단축키로 처리되지 않게 하기 위해서다.
- 검색창에 입력 중이면 포인터가 노드에 다시 들어와도 포커스를 가져가지 않는다.

검색은 목록의 행을 보이거나 숨기기만 한다. 고정 상태, 히트맵, 이미지 클릭으로
태그 고르기는 검색과 상관없이 동작한다. 숨겨진 태그도 고정이 유지되고
히트맵에 그려진다.

## 테스트 계획

변경이 브라우저 JS에만 있다. 이 리포의 테스트는 `pytest`뿐이므로 브라우저에서
직접 확인한다.

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 검색 | `background`를 입력한다 | `background`가 들어간 태그만 보인다 |
| 대소문자 | `BACKGROUND`를 입력한다 | 위와 같다 |
| 정규식 | `^see-`, `\(medium`을 입력한다 | 맞는 태그만 보인다 |
| 틀린 정규식 | `(`를 입력한다 | 모든 태그가 보이고 테두리가 빨갛다 |
| 띄어쓰기 | `white background`를 입력한다 | 띄어쓰기가 입력되고 태그가 고정되지 않는다 |
| 고정 유지 | 태그를 고정하고, 그 태그가 숨도록 검색한다 | 히트맵에 계속 그려지고, 검색어를 지우면 고정된 채로 보인다 |
| 화살표 키 | 검색한 뒤 목록에서 위아래 키를 누른다 | 보이는 태그 사이에서만 움직인다 |
| 다음 생성 | 검색어를 둔 채 다시 생성한다 | 검색어와 결과가 유지된다 |

## 테스트 결과

이 환경에는 브라우저와 `node`가 없어서 위 표의 브라우저 확인은 하지 못했다.
대신 `quickjs`로 `TagExplorerView.applySearch()`만 떼어 돌렸다. 태그는
`Simple Background`, `white background`, `oil painting \(medium\)`,
`see-through` 순으로 보이고 `white background`가 고정되어 있다.

| 검색어 | 보이는 태그 | 테두리 | 고정 |
|---|---|---|---|
| (빈 칸) | 4개 모두 | 기본 | 유지 |
| `background` | `Simple Background`, `white background` | 기본 | 유지 |
| `^see-` | `see-through` | 기본 | 유지 |
| `\(medium` | `oil painting \(medium\)` | 기본 | 유지 |
| `(` | 4개 모두 | 빨강 | 유지 |
| `zzz` | 없음 | 기본 | 유지 |

기존 `pytest` 15개는 수정 전후 모두 통과한다.
