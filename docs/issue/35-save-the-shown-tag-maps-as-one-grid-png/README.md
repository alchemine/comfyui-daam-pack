# #35 Save the shown tag maps as one grid PNG

이슈: https://github.com/alchemine/comfyui-daam-pack/issues/35

## 이슈

Tag Explorer에는 저장 기능이 없다. 태그별 맵을 비교하려면 태그를 하나씩 호버하며
화면을 캡처해야 한다.

## 해결책

`view` 버튼 아래에 `save` 버튼을 둔다. 누르면 지금 목록에 보이는 태그마다 그림을
그려 PNG 한 장의 격자로 모으고 `daam-tags.png`로 내려받는다.

- 태그는 목록에 보이는 순서(검색 결과, 점수순)대로 놓는다.
- 각 칸은 그 태그 하나를 호버했을 때 화면에 보이는 그림과 같다. strength,
  smooth, view, `tags` 설정이 그대로 반영된다.
- 각 칸 위에 태그 이름과 bar 점수를 적는다.
- 칸의 긴 변은 최대 512px이다. 이미지가 그보다 작으면 원래 크기로 둔다. 태그가
  많아도 브라우저의 캔버스 한도를 넘지 않게 하기 위해서다.
- 열 수는 1부터 태그 수까지 시험해서, 전체 너비 ÷ 전체 높이가 1에 가장 가까운
  값을 고른다. 칸의 높이에는 이름 줄이 들어간다.
- 도움말에 `save: shown tags as one png` 줄을 더한다.

화면 그리기와 저장이 같은 그림을 쓰도록, `draw()`에서 그림을 합성하는 부분을
태그 집합을 받는 함수로 떼어 낸다.

## 테스트 계획

변경이 브라우저 JS에만 있다. 이 리포의 테스트는 `pytest`뿐이므로 브라우저에서
직접 확인한다.

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 저장 | 노드를 실행하고 `save`를 누른다 | `daam-tags.png`가 내려받아진다 |
| 칸 | 저장한 PNG를 연다 | 칸마다 태그 이름과 점수가 있고, 그림이 그 태그를 호버했을 때와 같다 |
| 순서 | 저장한 PNG와 목록을 비교한다 | 목록 순서와 같다 |
| 검색 | `eye`로 검색하고 저장한다 | 검색에 맞는 태그만 들어 있다 |
| 비율 (세로 이미지) | 896×1152 이미지, 태그 1개, 7개, 40개로 저장한다 | 각각 열 수가 비율이 1에 가장 가까운 값이다 |
| 비율 (가로 이미지) | 1152×896 이미지로 같은 확인을 한다 | 위와 같다 |
| 설정 반영 | `view: mask`, `tags: off`로 바꾸고 저장한다 | 칸의 그림이 mask이고 태그 이름이 그림 위에 없다 |
| 화면 | 저장한 뒤 화면을 본다 | 저장 전과 같은 태그가 그려져 있다 |

## 테스트 결과

이 환경에는 ComfyUI 화면을 띄울 브라우저 세션이 없어서, `chrome-headless-shell`로
Tag Explorer만 떼어 실행했다. 맵은 태그마다 봉우리 하나인 인공 맵이고, 점수는
목록 순서대로 1에서 낮아지게 주었다. 내려받기 대신 `toBlob`을 가로채 격자 캔버스를
페이지에 그렸다. 고정한 태그는 1번이다.

| 확인 | 결과 |
|---|---|
| 저장 | `save`를 누르면 격자 캔버스 하나가 만들어진다 |
| 칸 | 칸마다 태그 이름과 점수가 있고, 그림이 그 태그 하나의 맵이다 |
| 순서 | 목록과 같은 점수순이다 |
| 검색 | `eye`로 검색하면 태그 40개 중 맞는 14개만 들어 있다 |
| 설정 반영 | `view: mask`, `tags: off`이면 칸이 mask이고 그림 위에 이름이 없다 |
| 화면 | 저장한 뒤에도 화면은 고정한 1번 태그를 그린다 |

Table 1. 이미지 크기와 태그 수별 열 수와 격자 비율. 기대 열 수는 같은 식을 Python으로 따로 계산한 값이다.

| 이미지 | 태그 수 | 열 수 (기대) | 격자 크기 | 너비 ÷ 높이 |
|---|---|---|---|---|
| 896×1152 | 1 | 1 (1) | 398×536 | 0.74 |
| 896×1152 | 7 | 3 (3) | 1194×1608 | 0.74 |
| 896×1152 | 14 (`eye` 검색) | 5 (5) | 1990×1608 | 1.24 |
| 896×1152 | 40 | 7 (7) | 2786×3216 | 0.87 |
| 1152×896 | 1 | 1 (1) | 512×422 | 1.21 |
| 1152×896 | 7 | 3 (3) | 1536×1266 | 1.21 |
| 1152×896 | 40 | 6 (6) | 3072×2954 | 1.04 |

실제 파일 내려받기는 ComfyUI에서 확인해야 한다.

기존 `pytest` 20개는 수정 전후 모두 통과한다.
