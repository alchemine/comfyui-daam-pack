# #31 Keep the Tag Explorer controls fixed while the tag list scrolls

이슈: https://github.com/alchemine/comfyui-daam-pack/issues/31

## 이슈

Tag Explorer의 오른쪽 패널은 통째로 스크롤된다. 태그 목록을 내리면 도움말,
슬라이더, 버튼, 검색창이 함께 위로 사라진다. 목록을 보면서 설정을 바꾸려면
다시 맨 위로 올라가야 한다.

## 해결책

태그 목록만 스크롤되게 한다.

- 패널을 세로 flex로 바꾸고, 패널 자체는 스크롤하지 않는다.
- 도움말, `strength`, `smooth`, `tags`, `view`, 검색창은 원래 높이를 유지한다.
- 태그 목록(`list`)이 남은 높이를 채우고, 넘치는 부분만 스크롤한다.
- 화살표 키로 움직인 행이 목록 밖에 있으면 목록이 그 행까지 스크롤된다.

## 테스트 계획

변경이 브라우저 JS에만 있다. 이 리포의 테스트는 `pytest`뿐이므로 브라우저에서
직접 확인한다.

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 고정 | 태그 40개를 넣고 목록을 끝까지 내린다 | 도움말부터 검색창까지 그대로 보이고, 목록만 움직인다 |
| 짧은 목록 | 태그 4개를 넣는다 | 스크롤바가 없고 모양이 전과 같다 |
| 화살표 키 | 목록에서 아래 키를 끝까지 누른다 | 커서가 있는 행이 항상 목록 안에 보인다 |
| 휠 | 목록 위에서 휠을 굴린다 | 목록만 스크롤되고 그래프는 확대되지 않는다 |

## 테스트 결과

이 환경에는 ComfyUI 화면을 띄울 브라우저 세션이 없어서, `chrome-headless-shell`로
Tag Explorer만 떼어 그렸다. 노드 크기는 900 × 520이다.

| 확인 | 수정 전 | 수정 후 |
|---|---|---|
| 고정 | 목록을 내리면 도움말부터 검색창까지 함께 올라간다 | 태그 40개 목록을 끝까지 내려도 도움말부터 검색창까지 그대로 보인다 |
| 짧은 목록 | 스크롤바가 없다 | 태그 4개에서 스크롤바가 없다 |
| 화살표 키 | 패널 전체가 스크롤된다 | 아래 키 40번 뒤 커서는 마지막 행이고, 그 행이 목록 안에 보인다. 패널은 스크롤되지 않는다 |

휠은 헤드리스로 확인하지 못했다. 그래프로 휠을 넘기지 않는 처리는 목록을 감싼
패널에 그대로 걸려 있다.

기존 `pytest` 20개는 수정 전후 모두 통과한다.
