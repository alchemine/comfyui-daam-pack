# #14 Keep pinned tags pinned across runs

이슈: https://github.com/alchemine/comfyui-daam-pack/issues/14

## 이슈

Tag Explorer에서 태그를 클릭해 고정해도, 다음 이미지를 생성하면 고정이 모두
풀린다. 같은 태그를 매번 다시 클릭해야 한다.

원인은 `setData()`가 새 결과를 받을 때마다 고정 상태를 지우는 것이다.

- `this.selected.clear()`가 고정을 모두 지운다.
- 고정 상태는 행 번호로 저장된다. 프롬프트가 바뀌면 같은 번호가 다른 태그를
  가리키므로 그대로 이어 쓸 수 없다.

## 해결책

- `setData()`가 `this.tags`를 바꾸기 전에 고정된 태그의 이름을 모아 둔다.
- 새 태그 중 이름이 같은 행을 다시 고정한다. 같은 이름이 없으면 고정하지 않는다.
- 상태는 화면 객체에만 둔다. 브라우저를 새로 고치면 사라진다.

태그 이름은 원문 그대로다(#12). 가중치 괄호는 이름에 들어가지 않으므로
`white background`를 `(white background:1.2)`로 바꿔도 고정이 유지된다.

## 테스트 계획

변경이 브라우저 JS에만 있다. 이 리포의 테스트는 `pytest`뿐이므로 브라우저에서
직접 확인한다.

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 같은 태그 유지 | 태그 하나를 클릭해 고정하고 다시 생성한다 | 그 태그가 고정된 채로 나온다 |
| 여러 태그 유지 | 태그 둘을 고정하고 다시 생성한다 | 두 태그 모두 고정된 채로 나온다 |
| 가중치 변경 | `white background`를 고정하고 `(white background:1.2)`로 바꿔 생성한다 | 고정된 채로 나온다 |
| 없는 태그 | 고정한 태그를 프롬프트에서 빼고 생성한다 | 아무 태그도 고정되지 않는다 |
| 새로 고침 | 태그를 고정하고 브라우저를 새로 고친 뒤 생성한다 | 아무 태그도 고정되지 않는다 |
