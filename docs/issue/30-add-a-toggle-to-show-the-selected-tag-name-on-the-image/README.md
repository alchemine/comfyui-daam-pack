# #30 Add a toggle to show the selected tag name on the image

이슈: https://github.com/alchemine/comfyui-daam-pack/issues/30

## 이슈

Tag Explorer에서 태그를 고정하거나 호버하면 히트맵만 그려진다.
그림만 보고는 지금 어떤 태그의 히트맵인지 알 수 없다.

## 해결책

`smooth` 슬라이더 아래에 `tags` 토글 버튼을 둔다.

- 버튼 글자는 `tags: on`과 `tags: off`이고, 기본값은 `on`이다.
- 버튼 모양은 `view` 버튼과 같다.
- `on`이면 히트맵에 그려진 태그마다 이름을 하나씩 그린다.
  - 호버 중이면 호버한 태그 하나의 이름만 그린다.
  - 호버 중이 아니면 고정한 태그의 이름을 모두 그린다.
- 이름은 그 태그의 맵에서 값이 가장 큰 칸의 가운데에 둔다.
- 글자는 흰색에 검은 테두리를 둘러, heatmap과 mask 어느 쪽 위에서도 읽히게 한다.
- `HELP_TEXT`에 `tags` 줄을 더한다.
- 설정은 다음 생성 때도 남고, 브라우저를 새로 고치면 기본값으로 돌아간다.

## 테스트 계획

변경이 브라우저 JS에만 있다. 이 리포의 테스트는 `pytest`뿐이므로 브라우저에서
직접 확인한다.

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 기본값 | 노드를 새로 만들고 실행한다 | 버튼이 `tags: on`이다 |
| 호버 | 목록에서 태그 하나에 포인터를 올린다 | 그 태그 이름이 히트맵의 가장 강한 곳에 보인다 |
| 고정 | 태그 두 개를 고정한다 | 두 이름이 각자의 가장 강한 곳에 보인다 |
| 끄기 | 버튼을 누른다 | 버튼이 `tags: off`가 되고 이름이 사라진다 |
| mask | `view: mask`로 바꾼다 | 이름이 어두운 곳에서도 읽힌다 |
| 선택 없음 | 고정도 호버도 없게 한다 | 이름이 그려지지 않는다 |
| 다음 생성 | `off`인 채로 다시 생성한다 | `off`가 유지된다 |

## 테스트 결과

이 환경에는 ComfyUI 화면을 띄울 브라우저 세션이 없어서, `chrome-headless-shell`로
Tag Explorer만 떼어 그렸다. 512 × 768 그림에 태그 4개를 고정하고, 각 태그의 맵은
서로 다른 칸에서 가장 크다.

| 확인 | 결과 |
|---|---|
| 기본값 | 버튼이 `tags: on`이고, 네 이름이 각자의 가장 강한 곳에 보인다 |
| 끄기 | 버튼을 누르면 `tags: off`가 되고 이름이 사라진다 |
| mask | `view: mask`에서도 흰 글자와 검은 테두리로 이름이 읽힌다 |
| 가장자리 | 맵이 맨 위 오른쪽과 맨 아래 왼쪽 칸에서 가장 큰 태그도 이름이 그림 안에 다 보인다 |

호버, 다음 생성, 선택 없음은 ComfyUI에서 확인해야 한다.

기존 `pytest` 20개는 수정 전후 모두 통과한다.
